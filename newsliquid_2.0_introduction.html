newsliquid-2.0-flash A low-latency market-news impact scorer for single-news triage

6551 News Research Evaluation summary and benchmark position
2.0 evaluation brief Leaderboard rank #2 Internal evaluation completed Public benchmark n = 200

Abstractnewsliquid-2.0-flash is a compact market-news impact model that reads one timestamped news item and one supplied target asset, then emits a single token in the form L85, S70, or N10. The 2.0 release expands the model from a crypto-first scorer into a broader market-impact system that can score crypto, equity indices, commodities, FX, rates, and other supplied instruments under the same target-asset contract.

On internal evaluation, newsliquid-2.0-flash reaches 88.08% direction accuracy, 0.879 macro-F1, and 10.52 impact-score MAE. On FinTech News Impact Benchmark v1, it records 85.20% output accuracy, 270.3 ms mean single-news latency, and 10.193 bits/s information rate. Inserted into the public leaderboard snapshot, this places newsliquid-2.0-flash at rank #2 by information rate.

1Model Position

The model is designed for the first pass of a real-time news pipeline: a headline or brief article arrives, the system supplies the asset or market instrument being scored, and the model returns a direction plus a short-horizon impact intensity. It is not a general chat model and it is not intended to write analysis prose. The useful output is intentionally narrow: one compact token that a routing system can parse without post-processing ambiguity.

The central improvement in newsliquid-2.0-flash is target-aware market coverage. A single headline can be bullish for one instrument and bearish for another; the model is evaluated on whether it can preserve that target-specific interpretation while remaining fast enough for a streaming news system.

This brief reports evaluation behavior and benchmark position. It intentionally omits implementation and distribution details.

2Scoring Interface

The scoring interface is intentionally narrow. Each request supplies the news timestamp, source, target instrument, and news content. The model returns one compact direction-impact label that can be consumed directly by downstream routing, alerting, or second-pass review systems.

Input fields
news time, source, target asset, and news content
Target field
generic market asset or instrument, not coin-only
Output
exactly one compact token, <direction><impact>
Directions
L = long, S = short, N = neutral
Impact
integer 0-100, interpreted as short-horizon direct market impact

The same headline can be scored differently for BTC, NASDAQ, gold, oil, or another supplied instrument because newsliquid-2.0-flash estimates direct impact on the named target rather than summarizing the news globally.

7Limitations and Honest Scope

This is a short-horizon interpretation model, not a realised-PnL oracle. Labels and predictions represent immediate analyst-grade market impact, typically on a 1-60 minute horizon. They do not assert that a future candle must move by the same magnitude.

Impact score calibration is deliberately separate from direction accuracy. Direction quality is high in internal evaluation, while exact label accuracy is stricter because it requires matching the numeric impact score as well as the signal. Downstream systems should usually parse direction and impact as two fields, then apply their own thresholds.

Latency is environment-sensitive. The public benchmark latency is an end-to-end run measurement. Hardware class, CUDA configuration, batching policy, network route, and serving framework can move the deployed latency materially.

Input-contract drift is the highest avoidable deployment risk. The model should receive a clearly supplied target instrument. Using it as a global news summarizer instead of a target-aware scorer changes the task being measured.

8Notes

  1. Benchmark position. The rank #2 statement is computed by inserting the newsliquid-2.0-flash public benchmark run into the existing public leaderboard snapshot, producing a 13-entry table.
  2. Information-rate framing. The benchmark score combines quality and latency. A slower model can have higher raw accuracy but a lower information-rate score.
  3. Accuracy reading. The 85.2% public output accuracy and 88.08% internal direction accuracy measure immediate analyst-grade interpretation, not realised future returns.
  4. Review surface. Important news rows score strongly; ambiguous market-stress and random-bucket rows remain the primary candidates for second-pass review.
